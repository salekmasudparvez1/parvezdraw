# Vision Suite UI Enhancement Plan

## Overview

Transform the current "Parvez Draw" whiteboard application into "Vision Suite" with a premium, modern UI inspired by VS Code-like interface designs. The goal is to create a professional-grade whiteboard tool with enhanced features, better visual design, and improved functionality.

---

## Phase 1: Branding & Identity Changes

### 1.1 Rename Application
- **File**: `packages/common/src/constants.ts`
  - Change `APP_NAME` from `"Parvez Draw"` to `"Vision Suite"`
- **File**: `excalidraw-app/App.tsx`
  - Update any hardcoded "Parvez Draw" references

### 1.2 Update Logo
- **File**: `public/logo.svg`
  - Create a new VS Code-inspired logo (blue/orange color scheme)
  - Use the existing logo structure but update colors to match the design
- **File**: `excalidraw-app/components/TopBar.tsx`
  - Update the logo SVG to match the new Vision Suite branding

## Phase 5: Canvas Search Implementation

### 5.1 Search Component
- **File**: `excalidraw-app/components/CanvasSearch.tsx` (NEW)
  
  **Features:**
  - Real-time search as user types
  - Results dropdown with element previews
  - Click result to select and zoom to element
  - Keyboard navigation (↑↓ arrows, Enter to select)
  - Escape to close

### 5.2 Integration with Excalidraw
- Use `excalidrawAPI.getSceneElements()` to get all elements
- Filter by text content, element name, or type
- Use `excalidrawAPI.scrollToContent()` to navigate to found elements

## Phase 6: Recording Quality Upgrade

### 6.1 Improved Recording Settings
- **File**: `excalidraw-app/components/DrawingRecorder.tsx`

  - Better codec selection (prefer VP9 over VP8)

### 6.2 Recording UI Enhancements
  - Add quality indicator during recording
  - Show estimated file size
  - Add pause/resume functionality
  - Better recording history with thumbnails
