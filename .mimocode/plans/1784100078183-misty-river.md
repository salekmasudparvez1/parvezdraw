## Task 2: Rename Internal Package from "excalidraw" to "prof"

**Scope**: Rename the internal package identifier, NOT the brand "Parvez Draw".

The CSS class `.excalidraw` is deeply embedded in ~50+ SCSS files. Renaming it would be a massive, risky refactor with no user-visible benefit. **Keep `.excalidraw` as the CSS root class** — it's an internal implementation detail.

1. **Package directory**: `packages/excalidraw/` → `packages/prof/`
2. **Package name** in `packages/prof/package.json`: `@prof/core` → `@prof/core`
3. **Sub-package names** (keep directory names, rename only package.json `name` field):
   - `packages/common/package.json`: `@excalidraw/common` → `@prof/common`

## Task 3: Drawing Recording Feature (Time-Lapse + Voice)

### Architecture

A new `DrawingRecorder` component that:
1. Records canvas frames at intervals (captureSnapshot every ~100ms)
2. Records microphone audio via `MediaRecorder` + `getUserMedia`
3. Captures canvas frames via `canvas.toDataURL()` or `canvas.captureStream()`
4. Merges audio + video using `MediaRecorder` with combined `MediaStream`
5. Saves the final WebM file locally via download + IndexedDB

### Key Design Decisions

- **Frame capture**: Use `canvas.captureStream()` on the Excalidraw canvas element to get a video stream, then combine with audio stream via `MediaRecorder`. This is more efficient than frame-by-frame screenshot capture.
- **Audio**: Use `navigator.mediaDevices.getUserMedia({ audio: true })` for live mic recording.
- **Merge**: Combine video stream (from canvas) + audio stream (from mic) into a single `MediaRecorder` output.
- **Save**: Download as `.webm` file + store metadata in IndexedDB for history.
- **Playback**: Store recordings in IndexedDB, allow replay in-app.

### New Files

1. **`excalidraw-app/components/DrawingRecorder.tsx`** — Main recording component (record button, timer, status indicator)
2. **`excalidraw-app/data/RecordingHistory.ts`** — IndexedDB storage for recordings (metadata + blob)
3. **`excalidraw-app/components/RecordingPanel.tsx`** — Panel to view/play past recordings

### Modified Files

1. **`excalidraw-app/components/TopBar.tsx`** — Add Record button (red dot icon)
2. **`excalidraw-app/App.tsx`** — Add recording state management, pass recording props

### Implementation Details

#### DrawingRecorder.tsx

```tsx
// State: isRecording, elapsedSeconds, audioEnabled
// On start:
//   1. Get canvas element via document.querySelector('.excalidraw canvas')
//   2. canvas.captureStream(30) → videoStream
//   3. navigator.mediaDevices.getUserMedia({ audio: true }) → audioStream
//   4. Combine streams: new MediaStream([...videoStream.getTracks(), ...audioStream.getTracks()])
//   5. new MediaRecorder(combinedStream, { mimeType: 'video/webm;codecs=vp9,opus' })
//   6. recorder.ondataavailable → collect chunks
//   7. recorder.start()
// On stop:
//   1. recorder.stop()
//   2. recorder.onstop → create Blob from chunks
//   3. Save to RecordingHistory (IndexedDB)
//   4. Trigger download as .webm file
```

### Recording Flow

1. User clicks Record button in TopBar
2. Browser prompts for microphone permission (first time only)
3. Recording starts: canvas stream + mic stream → MediaRecorder
4. TopBar shows pulsing red dot + elapsed timer
5. User draws normally — everything is captured
6. User clicks Stop (same button)
7. Recording saved to IndexedDB + auto-downloaded as .webm
8. Recording appears in RecordingPanel history
