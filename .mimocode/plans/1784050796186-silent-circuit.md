# Parvez Draw — Transformation Plan

Transform the Excalidraw codebase into **Parvez Draw**, an offline-first whiteboard application.

## Guiding Principles

- **Incremental phases** — each phase is independently testable and committable
- **Preserve monorepo structure** — keep `packages/*` and `excalidraw-app/` as-is
- **Keep internal `@excalidraw/*` package names** — renaming import paths across hundreds of files is high-risk for no user-facing benefit
- **Only change user-facing text** — "Excalidraw" in UI becomes "Parvez Draw"; internal code references stay
- **Remove, don't stub** — deleted features are gone cleanly, no dead code

## Phase 3: Local-First Storage Enhancement

**Goal:** Robust auto-save, version history, recent files, crash recovery.

### Implement

**Version History** (`excalidraw-app/data/VersionHistory.ts`) — NEW FILE:
- Store snapshots in IndexedDB with timestamps
- On each auto-save, if significant changes (element count delta > threshold or time since last snapshot > 5 min), store a snapshot
- Max 50 snapshots (FIFO eviction)
- Expose: `saveSnapshot(elements, appState)`, `getSnapshots()`, `restoreSnapshot(id)`

**Recent Files** (`excalidraw-app/data/RecentFiles.ts`) — NEW FILE:
- Maintain a list in localStorage: `{ id, name, lastModified, thumbnail? }`
- Max 20 entries (FIFO)
- Updated on save/load

**Crash Recovery** — Modify `excalidraw-app/App.tsx`:
- On startup, check if there's an unsaved state newer than the last confirmed save
- If so, show a toast: "We recovered your unsaved work"
- Use existing `isBrowserStorageStateNewer()` logic

**Local Backup** — Add to existing Export menu:
- "Export as Parvez Draw file (.parvezdraw)" — already exists as JSON export
- "Import Parvez Draw file" — already exists as load scene
- No additional work needed beyond the format rename

### Files to Create
- `excalidraw-app/data/VersionHistory.ts`
- `excalidraw-app/data/RecentFiles.ts`

### Files to Modify
- `excalidraw-app/App.tsx` — integrate version history, crash recovery

## Risk Assessment

| Risk | Mitigation |
|------|-----------|
| Removing collab breaks shared imports | Audit all import chains carefully; some types in `data/index.ts` may be imported elsewhere |
| Removing AI breaks TTD references | `TTDDialog` is imported from `@excalidraw/excalidraw` core; removing it from App.tsx is safe |
| Removing Sidebar breaks layout | Sidebar was optional; removing it won't affect core layout |
| File format rename breaks backward compat | Keep `.excalidraw` as accepted import extension |
| Build fails after removing deps | Run typecheck after each phase; fix import errors immediately |
